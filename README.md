# Anik Portfolio

A modern, feature-rich personal portfolio built with Next.js, React, and TypeScript. This project showcases my work, skills, and contact information, and includes advanced UI/UX, animations, and PWA support.

---

## 🚀 Features

- **Next.js 16**: Fast, SEO-friendly React framework
- **TypeScript**: Type-safe codebase
- **Tailwind CSS**: Utility-first styling
- **Advanced Animations**: GSAP, motion, and custom effects
- **3D Graphics**: Powered by @react-three/fiber and three.js
- **PWA Support**: Offline access and installable
- **Email Integration**: React Email & Resend for notifications
- **State Management**: Zustand
- **Accessibility**: Focus-visible, keyboard navigation
- **Performance**: Optimized images, code splitting, and more
- **Analytics**: Google Analytics integration

---

## 📦 Tech Stack

- **Framework**: Next.js, React
- **Styling**: Tailwind CSS, PostCSS
- **Animation**: GSAP, motion, Embla Carousel
- **3D/Canvas**: @react-three/fiber, three.js
- **State**: Zustand
- **Email**: React Email, Resend
- **PWA**: Serwist
- **Linting/Formatting**: Biome, Commitlint, Lefthook
- **Other**: Lucide, Radix UI, Sonner, clsx, zod

## 🛠️ Setup & Development

### Prerequisites
- Node.js >= 24.10.0
- pnpm (recommended)

### Install dependencies
```bash
pnpm install
```

### Development server
```bash
pnpm dev
```

### Build for production
```bash
pnpm build
```

### Lint & Format
```bash
pnpm lint      # Lint code
pnpm format    # Format code
```

### Type Checking
```bash
pnpm typecheck
```

## 📁 Project Structure

- `src/` — Main source code
  - `app/` — Next.js app directory
  - `components/` — UI, layout, SVG, and utility components
  - `emails/` — Email templates
  - `lib/` — Utilities and helpers
  - `stores/` — Zustand stores
  - `types/` — TypeScript types
- `public/` — Static assets (images, fonts, audio)
- `react-email-starter/` — Email starter templates
- `scripts/` — Utility scripts (e.g., image optimization)
