## Replace Resend with nodemailer (custom SMTP) in the contact form

**Scope:** swap the email transport in the server action only. The `Contact` form component, rate limiting, Zod validation, and reCAPTCHA stay untouched. The two emails (owner notification + visitor thank-you) and their React Email templates are reused verbatim.

### ⚠️ Acknowledged limitation (per your decision)
nodemailer opens a direct SMTP TCP connection (ports 25/465/587). **Vercel serverless blocks these ports**, so this will work in `next dev` locally but **time out / fail silently in production on Vercel**. A prominent comment at the top of `src/actions/email.ts` will document this so it isn't forgotten.

`resend` becomes unused. I'll leave it in `package.json` (removing a dependency is a separate decision) and note that you can `pnpm remove resend` later if desired.

### 2. Rewrite `src/actions/email.ts`
- Remove `import { Resend } from "resend"` and `const resend = new Resend(...)`.
- Add `import nodemailer from "nodemailer"` and `import { render } from "@react-email/render"`.
- Keep everything else identical: `getRequesterKey`, `getRateLimitConfig`, `verifyRecaptchaToken`, `formSchema`, `submitContactForm` signature/return shape, rate-limit + Zod + reCAPTCHA blocks.
- Add a lazily-built SMTP transporter (module-level singleton via a small helper, created on first use from env vars) so the connection is reused:
  ```ts
  let transporter: nodemailer.Transporter | null = null;
  function getTransporter() {
    if (transporter) return transporter;
    const port = Number(process.env.SMTP_PORT ?? 587);
    transporter = nodemailer.createTransport({
      host: process.env.SMTP_HOST,
      port,
      secure: port === 465,
      auth: { user: process.env.SMTP_USER, pass: process.env.SMTP_PASS },
    });
    return transporter;
  }
  ```
- Replace the two `resend.emails.send({...})` calls with `getTransporter().sendMail({...})`. Each `sendMail` will include:
  - `from: `"${process.env.SMTP_FROM_NAME ?? "Portfolio"}" <${process.env.EMAIL_FROM}>"`
  - notification: `to: process.env.CONTACT_EMAIL`, `replyTo: email`, subject `[Portfolio] ${subject}`, `html` = `render(ContactNotificationEmail({...}))`, plus a `text` fallback.
  - thank-you: `to: email`, subject `Thanks for reaching out!`, `html` = `render(ContactThankYouEmail({ name }))`, `text` fallback. Keep the existing fire-and-forget `.then()` error-logging pattern.
- Preserve existing error handling: if `sendMail` throws for the notification email, log + return the same `{ success: false, error: "Something went wrong..." }`.
